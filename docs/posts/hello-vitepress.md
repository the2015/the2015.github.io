# Hello VitePress

这是本博客的第一篇文章。博客正式开张 🎉

## 为什么要有这个博客

- **写下来才算学会。** 很多东西当时觉得自己懂了，过两周想再用，发现全忘了。写成文章是最好的复习。
- **踩过的坑要留痕。** 下次再遇到同样的问题，搜自己的博客比搜搜索引擎快。
- **输出倒逼输入。** 想把一个东西讲清楚，就得先把它真正弄明白。

## 技术栈

本站的技术选型很简单：

| 组件 | 选择 | 理由 |
| --- | --- | --- |
| 框架 | VitePress | Markdown 即文章，构建快，默认主题够好看 |
| 托管 | GitHub Pages | 免费、稳定、和代码仓库在一起 |
| 部署 | GitHub Actions | push 到 `main` 自动构建发布，零手动操作 |

具体部署过程写在[下一篇文章](./deploy-to-github-pages)里。
