# 订阅与联系

本站主要更新 Cloudflare 排障、GitHub Actions 自动化和个人项目部署。每篇文章尽量给出命令、验证过程和适用边界。

## 用 RSS 收到新文章

把下面的地址复制到你使用的 RSS 阅读器，添加为订阅源即可：

```text
https://the2015.github.io/feed.xml
```

也可以[直接打开 RSS](/feed.xml)。浏览器显示 XML 是正常的；订阅后，阅读器会显示文章标题、摘要和原文链接。无需在本站注册账号。

## 讨论或反馈

文章有错误、命令在你的环境下结果不同，可以到[博客仓库的 Issues](https://github.com/the2015/the2015.github.io/issues)反馈。带上文章链接、环境和已经做过的验证会更方便讨论；请删除凭据、私钥等敏感信息。

行情日报项目自身的问题可直接到 [notebook-market-daily](https://github.com/the2015/notebook-market-daily) 查看使用说明和提交 Issue。
